# Skeet Shooter

A simple C++ skeet shooting game project.

## Overview

This project contains the source code for a basic skeet shooter game, including:
- Player input handling
- Bird movement and shooting logic
- Scoring system
- Visual effects

## Project Structure

Key files:
- `game.cpp` / `skeet.cpp` - main game flow
- `bird.cpp` / `bird.h` - bird behavior
- `bullet.cpp` / `bullet.h` - bullet behavior
- `gun.cpp` / `gun.h` - gun mechanics
- `score.cpp` / `score.h` - scoring logic

## Build

This repository includes project files for:
- Visual Studio (`Skeet.sln`, `Skeet.vcxproj`)
- Xcode (`Skeet.xcodeproj`)

Open the project in your preferred IDE and build/run from there.

## Notes

This is a small educational-style game project and is intended to be easy to read and modify.
